Sources: Minecraft Wiki version pages (https://minecraft.wiki/w/Java_Edition_<ver>) and https://minecraft.wiki/w/Pack_format. ## 1.21 / 1.21.1 (data 48) - https://minecraft.wiki/w/Java_Edition_1.21 , .../Java_Edition_1.21.1
- Registry folders renamed to singular: `structures`->`structure`, `advancements`->`advancement`, `recipes`->`recipe`, `loot_tables`->`loot_table`, `predicates`->`predicate`, `item_modifiers`->`item_modifier`, `functions`->`function`, `tags/functions`->`tags/function`, `tags/items`->`tags/item`, `tags/blocks`->`tags/block`, `tags/entity_types`->`tags/entity_type`, `tags/fluids`->`tags/fluid`, `tags/game_events`->`tags/game_event`. Registry `decorated_pot_patterns`->`decorated_pot_pattern`.
- Data-driven (new JSON registries): `enchantment/<id>.json`, `painting_variant/<id>.json` (`width` 1-16, `height` 1-16, `asset_id`), `jukebox_song/<id>.json` (`sound_event`, `description`, `length_in_seconds`, `comparator_output` 0-15), plus `enchantment_provider`.
- Enchantment JSON fields: `description`, `exclusive_set`, `supported_items`, `primary_items`, `weight` (max 1024), `max_level` (max 255), `min_cost`/`max_cost` (`base`, `per_level_above_first`), `anvil_cost`, `slots` (any, hand, mainhand, offhand, armor, feet, legs, chest, head, body), `effects`. Effect conditions must be inline objects (no references).
- Enchantment effect component types: armor_effectiveness, attributes, ammo_use, block_experience, crossbow_charging_sounds, crossbow_charge_time, damage, damage_immunity, damage_protection, equipment_drops, fishing_luck_bonus, fishing_time_reduction, hit_block, knockback, item_damage, location_changed, mob_experience, post_attack, prevent_armor_change, prevent_equipment_drop, projectile_count, projectile_piercing, projectile_spread, projectile_spawned, repair_with_xp, smash_damage_per_block_fallen, tick, trident_return_acceleration, trident_spin_attack_strength, trident_sound.
- Level-based values: float, `linear`, `clamped`, `fraction`, `levels_squared`. Value effects: add, all_of, multiply, remove_binomial, set. Entity effects: all_of, apply_mob_effect, damage_entity, damage_item, explode, ignite, play_sound, replace_block, replace_disk, run_function, set_block_properties, spawn_particles, summon_entity.
- Enchantment tags (`tags/enchantment`): curse, prevents_*, smelts_loot, tradeable, on_traded_equipment, double_trade_price, in_enchanting_table, on_mob_spawn_equipment, on_random_loot, `exclusive_set/{armor,boots,bow,crossbow,damage,mining,riptide}`, `trades/<biome>_{common,special}`. Enchantment providers: `single_enchantment`, `enchantments_by_cost`, `enchantments_by_cost_with_difficulty`.
- Attribute modifiers: namespaced `id` replaces `uuid` + `name` (item components, enchantment attribute effects). `/attribute ... modifier add|remove|value get`: `uuid`/`name` -> `id`.
- Command item args: `!` prefix removes a default component: `diamond_pickaxe[!tool]` (/give, /item, /loot). New selector `@n` (= `@e[sort=nearest,limit=1]`).
- Loot: `random_chance.chance` is now a number provider. `random_chance_with_looting` -> `random_chance_with_enchanted_bonus` (removed `looting_multiplier`, `chance`; added `enchantment`, `unenchanted_chance`, `enchanted_chance`). Targets: `killer`->`attacker`, `direct_killer`->`direct_attacker`, `killer_player`->`attacking_player`. `looting_enchant`->`enchanted_count_increase` (+`enchantment`). `enchant_randomly`: `enchantments`->`options`, new `only_compatible` (default true). `enchant_with_levels`: `treasure` removed, `options` takes enchantment/list/`#tag`. `copy_name` sources: `killer`->`attacking_entity`, `killer_player`->`last_damage_player`. New: condition `enchantment_active_check`, number provider `enchantment_level`, function `set_ominous_bottle_amplifier`.
- Predicates: item sub-predicate `enchantment` -> `enchantments`; new item `jukebox_playable` (`song`); entity flags `is_on_ground`, `is_flying`; location `can_see_sky`, `weather` (clear/raining/thunder); entity `movement`, `periodic_tick`, `movement_affected_by`; player `gamemode` takes list; damage type `is_direct`; block `unobstructed`.
- Components: `custom_data` accepts SNBT string; `food.using_converts_to`; new `jukebox_playable` (`song`, `show_in_tooltip`).
- Entity fields: fireball `power` removed -> `acceleration_power` (dragon_fireball, large/small_fireball, fireball, breeze_wind_charge, wind_charge, wither_skull). Projectile `weapon` added, `ShotFromCrossbow` removed.
- Worldgen: `dimension_padding` (int or `{bottom, top}`), jigsaw `liquid_settings` (`apply_waterlogging`/`ignore_waterlogging`), `override_liquid_settings`, placement modifier `fixed_placement`, feature `end_platform`. Damage type `campfire` split from `in_fire`. Biome tag `#has_structure/trial_chambers`.
- New attributes (1.21 prefixes): generic.burning_time, generic.explosion_knockback_resistance, player.mining_efficiency, generic.movement_efficiency, generic.oxygen_bonus, player.sneaking_speed, player.submerged_mining_speed, player.sweeping_damage_ratio, generic.water_movement_efficiency. `generic.attack_knockback` applies to players.
- New content: trial chambers loot (`trial_chambers/...`), enchantments breach/density/wind_burst, wind charge etc. (1.21.1 only: `player_interacted_with_entity` now fires on sitting/standing tamed cat; command completion crash fix; still 48.)

## 1.21.2 / 1.21.3 (data 57) - https://minecraft.wiki/w/Java_Edition_1.21.2 , .../Java_Edition_1.21.3
- Attribute IDs lose prefixes: `generic.X` / `player.X` / `zombie.X` -> `X` (e.g. `generic.max_health` -> `max_health`). New `tempt_range`.
- `/rotate <target> <rotation>` | `... facing <pos>` | `... facing entity <target> [anchor]` (new).
- Recipes: ingredient `{"item":"x"}` -> `"x"`; `{"tag":"x"}` -> `"#x"`; tags no longer allowed inside item lists. `crafting_special_shulkerboxcoloring` -> `crafting_transmute` (`category`, `group`, `input`, `material`, `result`). Removed `crafting_special_suspiciousstew`. `smithing_transform`/`smithing_trim` `template`/`base`/`addition` now optional (no empty list). Loom banner recipes need the pattern item tag.
- Components: `fire_resistant` -> `damage_resistant` (`types`: damage type tag e.g. `#minecraft:is_fire`). `food` now only nutrition/saturation/can_always_eat; `eat_seconds`, `using_converts_to`, `effects` moved to new `consumable` (`consume_seconds` default 1.6, `animation`, `sound`, `has_consume_particles`, `on_consume_effects`; effect types apply_effects, remove_effects, clear_all_effects, teleport_randomly, play_sound). New: `death_protection` (`death_effects`), `enchantable` (`value`), `equippable` (`slot`, `equip_sound`, `model`, `allowed_entities`, `dispensable`, `swappable`, `damage_on_hurt`, `camera_overlay`; slot `body`), `glider`, `item_model`, `repairable` (`items`), `tooltip_style`, `use_cooldown` (`seconds`, `cooldown_group`), `use_remainder`, `damage_resistant`.
- `item_name` present on every item; name priority: written_book title > `custom_name` > potion_contents `custom_name` (new string field) > `item_name`. `minecraft:lock` (container `Lock` -> `lock`) is now an item predicate (`items`, `count`, `components`, `predicates`).
- Enchantment effect `damage_item` -> `change_item_damage` (accepts negatives); advancement `killed_by_crossbow` -> `killed_by_arrow` (+ optional `fired_from_weapon` item predicate). New trigger/effect type `projectile_spawned`.
- Loot: `empty` special loot table removed; sheep: single `entities/sheep` with colour sub-tables `entities/sheep/_<color>_`; new `shearing/{sheep,mooshroom,snow_golem}`; chicken eggs `gameplay/chicken_lay`; armadillo `gameplay/armadillo_shed`; `gameplay/hero_of_the_village/{unemployed,baby}_gift`. `/loot` errors on block with no loot table. Loot context tool value for `archaeology`, `vault`, `shearing`.
- Predicates: player `input` (forward, backward, left, right, jump, sneak, sprint); entity `minecraft:salmon` (`variant`); sheep `sheared`/`color`; removed `minecraft:boat` entity sub-predicate (boats are per-wood entity IDs, e.g. `oak_boat`, `oak_chest_boat`; entity tag `#boat`).
- Registries: `instrument` now data-driven (`sound_event`, `range`, `use_duration`, `description`); `painting_variant` gains optional `author`/`title` text components; `trial_spawner` registry (`normal_config`/`ominous_config` may reference it; inline still ok). Feature flags `bundle` removed. Raw JSON text: invalid `selector` now fails to parse. `/ride` cannot ride leash knots, lightning, bobbers.
- Particles: RGB/ARGB colours accept float vector or packed int (`trail.color`, `dust.color`, `dust_color_transition.from_color/to_color`); new particles `block_crumble` (`block_state`), `trail` (`color`, `target`).
- Game rules: `disablePlayerMovementCheck`, `minecartMaxSpeed`. TNT / TNT minecart `explosion_power`. Worldgen: removed `seagrass_simple`; trims on any equippable with equipment model.
- Many new tags (brewing_fuel, bundles, shulker_boxes, repairs_*_armor, *_tool_materials, mace_smash, ...). Entity x-rotation clamped -90..90.

## 1.21.4 (data 61) - https://minecraft.wiki/w/Java_Edition_1.21.4
- `equippable.model` -> `asset_id`. `custom_model_data` is now `{floats, flags, strings, colors}` lists; loot function `set_custom_model_data` same four fields (list ops, e.g. `"mode":"replace_all"`).
- Item model definitions: `assets/<ns>/items/<name>.json` replace block-model `overrides` (removed); selected by `item_model` component. Types composite/condition/empty/model/range_dispatch/select/special/bundle/selected_item; properties incl. `has_component`, `using_item`, `component`, `custom_model_data`, etc. (resource-pack side).
- Text components: new `shadow_color` style (packed ARGB int or RGBA float array; 0 disables).
- `/attribute <t> <attr> base reset` (new). `/setblock`/`/fill` fixed for multi-state blocks; `/data remove` works on CustomName etc. Data generator: server `net.minecraft.data.Main` no longer emits assets (`--client` removed); client jar has `net.minecraft.client.data.Main`.
- Entity/block entity NBT: TNT minecart `TNTFuse` -> `fuse`; minecart `explosion_speed_factor`; furnace `CookTime`->`cooking_time_spent`, `CookTimeTotal`->`cooking_total_time`, `BurnTime`->`lit_time_remaining`, new `lit_total_time`.
- `trim_material`: `item_model_index` removed. Particle `trail` requires `duration`. `block_entity_data` component applies only when `id` matches placed block entity.
- Biome `music` is now a weighted list of `{data, weight}`; new `music_volume`. `simple_block` feature: optional `schedule_tick`.
- Tags: removed `#tall_flowers` (block/item), item `#flowers`, `#trim_templates`; block `#tall_flowers`->`#flowers`; item `#flowers`->`#bee_food`; new `#bee_attractive`, `#skeleton_preferred_weapons` etc. Loot: resin from creaking heart, many blocks drop with any tool, lantern no pickaxe requirement. New resin recipes. Feature flag `winter_drop` removed.

## 1.21.5 (data 71) - https://minecraft.wiki/w/Java_Edition_1.21.5 (biggest break)
- Text components are NBT/SNBT, not JSON strings: `custom_name='{"text":"X"}'` -> `custom_name={text:'X'}`; `/tellraw`, `/title`, `/scoreboard` styled number format take SNBT. `/bossbar`, `/scoreboard`, `/team` text args resolve in context of `@s`.
- `hoverEvent` -> `hover_event`; `show_text`: `contents`->`value`; `show_item`: contents inlined (`id`,`count`,`components`), `text`->`value` n/a; `show_entity`: contents inlined, `id`->`uuid`, `type`->`id`.
- `clickEvent` -> `click_event`; `open_url`: `value`->`url` (http/https only); `run_command`: `value`->`command`; `suggest_command`: `value`->`command`; `change_page`: `value`->`page` (int).
- SNBT: scientific notation, `0x`/`0b` ints, `_` digit separators, integers may not start with 0, `s`/`u` suffix prefixes (`240ub`), string escapes (`\x \u \U \N{}` etc.), unquoted strings can't start with digit/`.`/`+`/`-`, trailing commas allowed, typed arrays accept smaller types, heterogeneous lists allowed (`['a',{b:3}]`, stored wrapped as `{'':'a'}`), new functions `bool(x)`, `uuid(str)`, `NaN/Inf` rejected. `/data` handles heterogeneous lists; paths with empty key not traversable.
- Commands: new `/test` (clearall, clearthat, clearthese, create, locate, resetclosest, resetthese, resetthat, pos, run, runclosest, runfailed, runmultiple, runthat, runthese, stop, verify). `strict` option (no block/shape updates) on `/fill`, `/clone`, `/setblock`, `/place template`. New syntax: `fill <from> <to> <block> keep`; `fill ... <block> [replace <filter>] [strict|destroy|hollow|outline]`; `setblock <pos> <block> [destroy|keep|replace|strict]`; `clone [strict] [[replace|masked|filtered <filter>] [force|move|normal]]`; `place template ... [<rotation> [<mirror> [<integrity> [<seed> [strict]]]]]`. Numbers again accepted for booleans in inline args (reverted). `/setblock`/`/fill` block entity data: omitted = keep, given = set, `{}` clears.
- Item components inline-flattened: `attribute_modifiers` `{modifiers:[..]}` -> `[..]`; `can_place_on`/`can_break` `{predicates:[..]}` -> inline (single predicate ok); `dyed_color` `{rgb:N}` -> `N` (or float array); `enchantments`/`stored_enchantments` `{levels:{..}}` -> `{..}`. `show_in_tooltip` removed from attribute_modifiers, can_place_on, can_break, dyed_color, enchantments, stored_enchantments, jukebox_playable, trim, unbreakable; `hide_tooltip`, `hide_additional_tooltip` removed -> new `tooltip_display` {`hide_tooltip`, `hidden_components`}. `toggle_tooltips` loot fn accepts any component.
- New components: `blocks_attacks`, `weapon` (`item_damage_per_attack`, `disable_blocking_for_seconds`), `potion_duration_scale`, `provides_banner_patterns`, `provides_trim_material` (trim material no longer names an item; trim pattern too - item moves to recipe), `break_sound`, `equippable.equip_on_interact`, `tool.can_destroy_blocks_in_creative`, `custom_data` on all entities (`data`), variant components `axolotl/variant, cat/collar, cat/variant, chicken/variant, cow/variant, fox/variant, frog/variant, horse/variant, llama/variant, mooshroom/variant, painting/variant, parrot/variant, pig/variant, rabbit/variant, salmon/size, sheep/color, shulker/color, tropical_fish/{base_color,pattern,pattern_color}, villager/variant, wolf/collar, wolf/variant, wolf/sound_variant`.
- Predicates: block predicates gain `components` (exact) and `predicates` (partial); entity predicates gain `components`/`predicates`. REMOVED entity sub-predicates (use components): axolotl, fox, mooshroom, rabbit, horse, llama, villager, parrot, salmon, tropical_fish, painting, cat, frog, wolf, pig; `sheep.color` removed.
- Entity NBT: `ArmorItems`/`HandItems`/`body_armor_item` -> `equipment` map {head,chest,legs,feet,mainhand,offhand,body,saddle}; `ArmorDropChances`/`HandDropChances`/`body_armor_drop_chance` -> `drop_chances` map; pig/strider `Saddle` -> `equipment.saddle`; slot `horse.saddle` -> `saddle`. `FallDistance` -> `fall_distance` (double). `SleepingX/Y/Z` -> `sleeping_pos`. Player `SpawnX/Y/Z,SpawnAngle,SpawnDimension,SpawnForced` -> `respawn` {pos, angle, dimension, forced}; `enteredNetherPosition` -> `entered_nether_pos`. `TileX/Y/Z` -> `block_pos` (item_frame, painting, leash_knot). Phantom `Size`->`size`, `AX/AY/AZ`->`anchor_pos`; vex `LifeTicks`->`life_ticks`, `BoundX/Y/Z`->`bound_pos`; turtle `HomePos*`->`home_pos`, `HasEgg`->`has_egg`; allay `CanDuplicate` removed; dolphin `TreasurePos*` removed; minecart `CustomDisplayTile` removed; entity `potion` split into `splash_potion` + `lingering_potion`; area_effect_cloud `potion_duration_scale`. Many defaults no longer written.
- Data-driven variants: `pig_variant` (`texture`->`asset_id`, `biome`->`spawn_conditions`, `model`), `cow_variant`, `chicken_variant`, `wolf_variant` (`*_texture`->`assets.{angry,tame,wild}`), new registries `cat_variant`, `frog_variant`; `spawn_conditions: [{priority, condition}]` with `minecraft:biome`, `moon_brightness`, `structure`; `wolf_sound_variant` registry.
- Recipes: `crafting_transmute.result` may be object `{id,count,components}`; `smithing_transform.base` required; `smithing_trim`: base/template/addition required + new `pattern` field. Lodestone uses iron ingot.
- Game test registries `test_environment` (all_of, function, game_rules {bool_rules,int_rules}, weather, time_of_day) and `test_instance` (environment, structure, max_ticks, setup_ticks, required, rotation, manual_only, sky_access, max_attempts, required_successes, type block_based|function). Entry point `net.minecraft.gametest.Main`.
- Misc: advancement `background` drops `textures/` prefix and `.png`; biome effects `dry_foliage_color`; `tinted_leaves` particle `color`; game rules `allowFireTicksAwayFromPlayer`, `tntExplodes`; tag `#dead_bush_may_place_on` -> `#dry_vegetation_may_place_on`, removed `#default_spawns`, `#full_moon_spawns`; many new tags (#eggs, #flowers, #can_equip_saddle, #spawns_*_variant_farm_animals, #on_*_village_maps ...). Fallen tree feature. Advancement "Country Lode, Take Me Home" moved to Adventure.

## 1.21.11 (data 94.1) - https://minecraft.wiki/w/Java_Edition_1.21.11
- Commands: new `/stopwatch create|query <id> [scale]|restart|remove`; `execute if|unless stopwatch <id> <range>`; `/worldborder` `time` args default to ticks (accept `s`/`d` suffixes); resource suggestions work for any namespace; item predicates accept empty `*[instrument]` == `*[instrument~{}]`; component existence `{<type>: {}}`.
- Game rules moved into a registry, snake_case ids (examples): `announceAdvancements`->`show_advancement_messages`, `commandBlocksEnabled`->`command_blocks_work`, `command_modification_block_limit`->`max_block_modifications`, `disableElytraMovementCheck`->`elytra_movement_check` (inverted), `disablePlayerMovementCheck`->`player_movement_check` (inverted), `disableRaids`->`raids` (inverted), `doDaylightCycle`->`advance_time`, `doEntityDrops`->`entity_drops`, `doImmediateRespawn`->`immediate_respawn`, `doInsomnia`->`spawn_phantoms`, `doLimitedCrafting`->`limited_crafting`, `doMobLoot`->`mob_drops`, `doMobSpawning`->`spawn_mobs`, `doPatrolSpawning`->`spawn_patrols`, `doTileDrops`->`block_drops`, `doTraderSpawning`->`spawn_wandering_traders`, `doVinesSpread`->`spread_vines`, `doWardenSpawning`->`spawn_wardens`, `doWeatherCycle`->`advance_weather`, `maxCommandChainLength`->`max_command_sequence_length`, `maxCommandForkCount`->`max_command_forks`, `naturalRegeneration`->`natural_health_regeneration`, `snowAccumulationHeight`->`max_snow_accumulation_height`, `spawnRadius`->`respawn_radius`, `spawnerBlocksEnabled`->`spawner_blocks_work`. Removed `doFireTick`, `allowFireTicksAwayFromPlayer` -> `fire_spread_radius_around_player` (-1/0/n). Other rules not listed in the renamed set (e.g. keepInventory, mobGriefing, randomTickSpeed, fall damage...) - exact new ids NOT verified. Namespaced, so likely `minecraft:` prefix required in `/gamerule` ids: verify in commands.json.
- Game test `game_rules` environment: `bool_rule`/`int_rule` -> single `rules` map.
- Dimension type: new `attributes`, `timelines` (id | list | timeline tag); `effects` REMOVED -> `skybox` (none|overworld|end) + `cardinal_light` (default|nether); `fixed_time` -> boolean `has_fixed_time`; fields migrated to attributes: `ultrawarm`, `bed_works`, `respawn_anchor_works`, `cloud_height`, `piglin_safe`, `has_raids`, `natural` (partly) (wiki lists these both as "migrated" and as retained in an environment-attribute table; check generated vanilla-data before relying on removal).
- Biome: new `attributes`; `effects.fog_color`, `water_fog_color`, `sky_color`, `particle`, `ambient_sound`/`mood_sound`/`additions_sound`, `music`, `music_volume` -> attributes `minecraft:visual/fog_color`, `visual/water_fog_color`, `visual/sky_color`, `visual/ambient_particles`, `audio/ambient_sounds`, `audio/background_music`, `audio/music_volume`. `effects` colour fields accept `"#rrggbb"` or float `[r,g,b]`. Biome tags removed: `#snow_golem_melts`, `#increased_fire_burnout`, `#plays_underwater_music`, `#has_closer_water_fog`, `#without_patrol_spawns`.
- New data: `timeline/<id>.json` (`period_ticks`, `tracks` attr->{`ease`,`modifier`,`keyframes`[{ticks,value}]}); environment attributes `visual/*`, `audio/*`, `gameplay/*` with modifiers (e.g. `blend_to_gray`); tags `#universal #in_overworld #in_nether #in_end` (timeline); `zombie_nautilus_variant` registry (experimental).
- Components new: `attack_range`, `damage_type`, `kinetic_weapon`, `minimum_attack_charge`, `piercing_weapon`, `swing_animation`, `use_effects`; `consumable.animation` `spear`->`trident` (new `spear` anim); `intangible` shows in tooltip. Item model `swap_animation_scale`, `spear_in_hand`.
- Loot: new function `discard`; `filtered` function: `modifier` -> `on_pass` / `on_fail`; new pool entry `slots` (`slot_source`); slot sources `empty`, `group`, `slot_range`, `contents`, `filtered`, `limit_slots`.
- Enchantments: new `exponent` (`base`,`power`), effect component `post_piercing_attack`, entity effects `apply_exhaustion`, `apply_impulse`; `play_sound` accepts per-level list; enchantment Lunge; tags `#enchantable/sword` -> `#enchantable/sweeping` / `#enchantable/melee_weapon`, `#swords` -> `#enchantable/melee_weapon` replaces `#enchantable/sharp_weapon`, new `#spears`.
- Entity NBT: `AngryAt` -> `angry_at`; `AngerTime` removed -> `anger_end_time` (long). Advancement trigger `spear_mobs` (`player`, `count`). Effect `breath_of_the_nautilus`. MSMP management protocol 2.0.0.
