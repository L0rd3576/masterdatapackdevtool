## 0. Version numbering and pack formats  (sources: VH, PF, DP, 26.x pages, beebom.com 26.1 snapshot-1 article)
- Scheme change: `1.x` numbering dropped. New Java scheme is `<year>.<drop>[.<hotfix>]`: 26.1 = first drop of 2026, 26.1.1/26.1.2 = hotfixes; first release of a drop has no hotfix number (plain 26.2). Last 1.x release: 1.21.11 (Dec 2025). Snapshots use the same scheme ("26.1 Snapshot 1", first on 2025-12-16). 3-4 drops/year expected.
- Release dates: 26.1 "Tiny Takeover" 2026-03-24 (26.1.1 04-01, 26.1.2 04-09); 26.2 "Chaos Cubed" 2026-06-16; 26.3 "Wilderness Bound" 2026-09-15; 26.4 in development (snapshots from 2026-09-22; pages mention snap-3).
- Java 25 required since 26.1 (Java SE 25). 26.1 is the first fully unobfuscated release. Protocol/data versions: 26.1 = 775 / 4786; 26.2 = 776 / 4903; 26.3 = 777 / 5023.
- Pack format is now `major.minor` (minor numbers introduced in 25w31a, first release 1.21.9). Non-breaking changes bump minor, breaking bump major. `pack.mcmeta` uses `min_format` / `max_format` (as two-number arrays, e.g. `[88, 0]`; the wiki also shows plain `88`) instead of `pack_format`; `supported_formats` and `pack_format` are not documented any more on the Data pack page. `overlays` (since 1.20.2/23w31a) and `filter` (22w11a) still documented; no overlay format change found for 26.x.

## 26.1  "Tiny Takeover"  (2026-03-24; data 101.1, resource 84.0)   source: [26.1], [TC], https://minecraft.wiki/w/Commands/swing, /fetchprofile

### Commands
- NEW `/swing [<targets>] [mainhand|offhand]` : makes entities swing arm. Targets default `@s`, hand default `mainhand` (defaults added in snap 3). Later (26.3 snap 7) gained `[whack|stab|none] [<duration>]` args.
- `/fetchprofile entity <single entity selector>` added (prints profile info for players and mannequins).
- `/time` is now world-clock based: `/time [of <clock>] set <time|timemarker>`, `add`, `pause`, `resume`, `query <timeline>`, `query <timeline> repetition`, `query time`, `query gametime`, `rate <float >0..1000>`. No clock = dimension's `default_clock`. `set`/`add` now return total elapsed clock ticks. `set <timemarker>`: overworld markers `day`, `noon`, `night`, `midnight`.
- Game rules UI: moved to World Options screen in pause menu, with search bar (no ID changes).

### Registries / new data folders
- NEW `world_clock` registry: `data/<ns>/world_clock/<id>.json` (empty object); `minecraft:the_end` added (overworld clock existed). Time markers `minecraft:wake_up_from_sleep`, `minecraft:roll_village_siege`.
- `timeline`: new REQUIRED `clock` field (use `minecraft:overworld` for old behaviour); optional `time_markers` map (int, or object with `ticks`, `show_in_commands` default false).
- dimension_type: new `default_clock` and `has_ender_dragon_fight`.
- Predicate `minecraft:time_check`: new `clock` (world clock id). Game tests: `time_of_day` -> `clock_time` (+ `clock`), new `timeline_attributes`/`timelines`.
- NEW data-driven villager trades: `villager_trade` (fields `wants`, `additional_wants`, `gives`, `given_item_modifiers`, `max_uses`, `reputation_discount`, `xp`, `merchant_predicate`, `double_trade_price_enchantments`) and `trade_set` (`trades`, `amount`, `allow_duplicates`, `random_sequence`). Trade tags `#<profession>/level_<1..5>`, `#common_smith/level_<n>`, `#wandering_trader/{buying,special,common}`. Removed enchantment tags `trades/{desert,jungle,plains,savanna,snow,swamp,taiga}_special`. Loot context `minecraft:villager_trade` (`this`,`origin`). (26.3 renames `given_item_modifiers` -> `given_item_modifier`.)
- NEW sound variant registries: `cat_sound_variant`, `pig_sound_variant`, `cow_sound_variant` (ambient/hurt/death/step), `chicken_sound_variant` (`adult_sounds`,`baby_sounds`); `wolf_sound_variant` adult sounds moved into `adult_sounds`, new `baby_sounds`. Cat/pig fields: `ambient_sound`,`stray_ambient_sound`,`hiss_sound`,`hurt_sound`,`death_sound`,`eat_sound`,`beg_for_food_sound`,`purr_sound`,`purreow_sound` (cat); `ambient/hurt/death/step/eat_sound` (pig).
- Inventory slot names: `villager.*` removed -> `mob.inventory.*`.
- Number providers: `minecraft:environment_attribute` (`attribute`), `minecraft:sum` (`summands`); int provider `trapezoid` (`min`,`max`,`plateau`). Predicate `minecraft:environment_attribute_check` (`attribute`,`value`).
- Loot functions: `set_random_dyes` (`number_of_dyes`), `set_random_potion` (`options`); `enchant_with_levels`/`enchant_randomly` gain `include_additional_cost_component`; `set_instrument.options` accepts ids. Name tag removed from ancient city + woodland mansion loot.
- Env attributes: `visual/block_light_tint`, `visual/ambient_light_color`, `visual/night_vision_color`, `gameplay/turtle_egg_hatch_chance` (def 0.002). Particles `pause_mob_growth`, `reset_mob_growth`.
- Entity predicate `player`: new `food` (`level` int range, `saturation` float range). Entity data: `current_explosion_impact_pos`, `current_impulse_context_reset_grace_time` added; `ignore_fall_damage_from_current_explosion` removed from players.
- Enchantment: `post_piercing_attack` no longer requires food level.
- Many tags: `#supports_*` family (replacing renames: `dry_vegetation_may_place_on`->`supports_dry_vegetation`, `bamboo_plantable_on`->`supports_bamboo`, `small_dripleaf_placeable`->`supports_small_dripleaf`, `big_dripleaf_placeable`->`supports_big_dripleaf`, `mushroom_grow_block`->`overrides_mushroom_light_requirement`, `snow_layer_can_survive_on`->`support_override_snow_layer`, `snow_layer_cannot_survive_on`->`cannot_support_snow_layer`), `#grows_crops`, `#cannot_support_seagrass/kelp`, `#enables_bubble_column_*`, `#substrate_overworld`, `#ice_spike_replaceable`, `#prevents_nearby_leaf_decay`, `#cannot_replace_below_tree_trunk`; `#dirt` split into `#mud`,`#moss_blocks`,`#grass_blocks`; item tags `#metal_nuggets`,`#dyes`,`#loom_dyes`,`#loom_patterns`,`#cat_collar_dyes`,`#wolf_collar_dyes`,`#cauldron_can_remove_dye`; fluid tags `#supports_lily_pad`,`#supports_frogspawn`,`#supports_sugar_cane_adjacently`,`#bubble_columns_can_occupy`; potion tag `#tradeable`; entity tag `#cannot_be_age_locked`; configured feature tag `#can_spawn_from_bone_meal` (Bone Meal now data-driven); `#dyeable` item tag removed; `golden_dandelion` added to small_flowers/flower_pots/piglin_loved.

### Recipes (all 26.1)

### Worldgen (26.1)
- `forest_rock` -> `block_blob` (+`state`,`can_place_on`); `ice_spike` -> `spike` (+`state`,`can_place_on`,`can_replace`); huge mushrooms gain `can_place_on`; `alter_ground` `provider` rule-based; `tree`: `force_dirt`+`dirt_provider` -> `below_trunk_provider`; new block state provider `rule_based_state_provider` (`fallback`,`rules`); removed feature types `flower`,`flower_no_bonemeal`,`random_patch`; `count` placement max 256->4096.

## 26.3  "Wilderness Bound"  (2026-09-15; data 121.0, resource 97.1)   source: [26.3], https://minecraft.wiki/w/Commands/compute, /posteffect, /swing

### Commands
- NEW `/compute <default | block <pos> | entity <target>> <provider> [<scale>]` (float mode, default scale 1.0, result floored) or `... integer` (int mode; no scale; intermediate steps truncate). Evaluates `context_int_provider` / `context_float_provider` number providers in a loot-like context (`minecraft:command_compute_default|_position|_entity`; `entity` exposes `target_entity`, `block` exposes block state/entity). Fails on eval error (e.g. div by 0). Works with `execute store`. Perm 2. Added 26.3 snap 10 (https://minecraft.wiki/w/Commands/compute).
- NEW `/data modify ... set|append|insert|merge|prepend ... compute <target> integer|float <provider>` source.
- NEW `/posteffect add|clear <players> [<posteffect>]`, `list <target>`, `remove <players> <posteffect>`: applies client-side post-process shaders from resource packs (`post_effect` folder). Vanilla ids `blur`, `creeper`, `entity_outline`, `invert`, `spider`. Server cannot verify they apply. Added 26.3 snap 3.
- `/swing`: new optional `[whack|stab|none]` (def whack) and `[<duration>]` (units d/s/t, def 6t); no longer resets player attack strength (snap 7).
- Slot sources in commands: `/execute if|unless items` and `/item` slot args now use slot sources (loot type `minecraft:command_slot_source`, params `container`,`origin`,`this_entity`); `/item replace` pairs source items 1:1 with destination slots; NEW `/item fill` (repeat source items to fill destination) and `/item override` (clears unmatched destination slots); `/item from entity` accepts multi-entity selectors; NEW `/execute if|unless slots`.
- `/give` over-limit amount now errors; `/tick step`, `/tick step stop`, `/tick sprint stop` signal errors instead of returning 0; `/place feature` allows inline feature definition; `/publish` loses `gamemode` argument (use `/defaultgamemode` or `/gamemode`); `/spreadplayers` safe blocks via `#entities_can_teleport_to`; `/team join|leave` counts only changed entities; `/tellraw` `nbt` components resolved up to 64k times; `/locate` faster.
- Still existing, unchanged per wiki: `/stopwatch`, `/waypoint`, `/dialog`, `/test`, `/fetchprofile` (no 26.3 changes recorded; strings for `/stopwatch` get typo fixes).

### Number providers rework (BREAKING)
- Registry `number_provider` replaced by `context_int_provider` + `context_float_provider` (loot tables use them: `rolls` -> int provider, `bonus_rolls` -> float provider).
